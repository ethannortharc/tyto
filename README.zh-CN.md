# Tyto · 听懂对话，接得上话

[English](README.md) · **中文**

macOS 上的悬浮会议助手。把会议变成原文与译文对照的字幕，点一句话就能获得回复建议，也能把准备好的讲稿放在会议旁边。

## 开会时能帮你什么

- **听懂两边的对话。** 分开采集会议软件的声音和麦克风，原文下面显示译文；自动标记问题、高亮日期、金额和自定义关键词。
- **组织好下一句话。** 选中一句或多句，结合会议背景和勾选的技能生成回复：对方是什么意思、你可以怎么说、中文如何理解。
- **跟上自己的讲稿。** 在独立提词器里打开 Markdown、HTML 或纯文本；跟读高亮正在说的段落，对方提到其他章节时给出跳转提示。
- **按场景调整大小。** 完整悬浮窗、字幕条、按钮条，一键切换，各自记住位置。
- **会后留得下来。** 保存字幕与回复，在会议记录里搜索、导出 Markdown，或者继续上次的会议。

Tyto 会把自己的窗口排除在屏幕采集之外。系统提示框和部分 macOS 菜单仍可能出现，详见[共享验证](docs/share-check.md)和[已知限制](#已知限制)。

## 不止是字幕

### 讲到哪里，提词器跟到哪里

提词器可以独立摆放，支持章节导航、跟读和话题提示。匹配在本机完成，同时利用原文和译文；讲稿文件改了，窗口也会自动更新。

### 截一张图，准备好回复

在聊天或邮件上按 **⌃⌥S**，Tyto 读取上下文，给出三种回复，第一条自动复制到剪贴板。想换语气或语言，在下方补一句要求，再点「重新生成」。

## 快速开始

**需要 Apple 芯片的 Mac，系统为 macOS 26 或更高版本。**

1. 从 [Releases](https://github.com/ethannortharc/tyto/releases) 下载最新的 `Tyto-x.y.z.dmg`，拖入「应用程序」后打开。
2. 在「翻译」里选择主语言，按需下载 Apple 语言包。本机字幕与翻译不需要 API Key。
3. 要使用回复建议，在「模型与服务」里添加服务商，再到「用途 → 回复」选择模型。密钥保存在 macOS 钥匙串。
4. 按 **⌃⌥L**，按系统提示允许「系统音频录制」和「麦克风」。使用截屏回复还需开启「屏幕与系统音频录制」权限，然后重新打开 Tyto。

会前在「会话」填写目的、参会者和关键词；会中选一句字幕，按 **⌃⌥R**；会后在 ⋯ 菜单选择「保存到会议记录」。

界面支持中英文，可在菜单栏常驻、登录时启动。更新会在退出时安装，下载后先验证签名。详见[安装与首次使用](docs/guide.zh-CN.md#安装)。

## 常用快捷键

会议软件在前台时也能使用。**⌃⌥** 表示 Control + Option。

| 快捷键 | 操作 |
|---|---|
| ⌃⌥L | 开始 / 停止听 |
| ⌃⌥R | 回复选中的话，或最近的话 |
| ⌃⌥S / ⌃⌥A | 截屏回复 / 框选区域 |
| ⌃⌥M | 完整悬浮窗 → 字幕条 → 按钮条 |
| ⌃⌥B | 显示 / 隐藏回复面板 |
| ⌃⌥N | 显示 / 隐藏提词器 |
| ⌃⌥↑ / ⌃⌥↓ | 上一节 / 下一节讲稿 |
| ⌃⌥J | 跳到对方刚提到的章节 |

[全部快捷键与外观设置 →](docs/guide.zh-CN.md#快捷键)

## 选择在哪里处理数据

| 用途 | 在本机处理 | 可选云端服务 |
|---|---|---|
| 语音识别 | Apple 本机识别 | 实时识别服务、转写接口或音频模型 |
| 翻译 | Apple 本机翻译 | 自选大模型 |
| 回复 | Ollama / LM Studio 本机模型 | Anthropic、OpenAI、OpenRouter、Gemini 等服务商 |
| 读取截图 | Apple OCR 或本机视觉模型 | 回复模型或单独的视觉服务商 |
| 提词器匹配、会议记录 | 本机匹配、本地文件 | — |

使用云端服务时，相应的音频、文本或图片会交给你选择的服务商。本机识图可以让**图片**留在本地，但提取出的文字仍可能交给云端回复模型。详见[模型与服务](docs/guide.zh-CN.md#模型与服务)及[完整数据流说明](docs/guide.zh-CN.md#隐私哪些数据会离开这台-mac)。

## 已知限制

- 系统声音包含除 Tyto 之外所有 App 的声音，其他音乐和视频也可能进入字幕。
- 文件选择器、权限提示、钥匙串提示和 macOS 菜单栏可能出现在共享画面中。Chrome 中的 Google Meet 尚未直接实测。
- 实时语音服务已做本地协议测试，真实长会议的验证仍待完成。
