# Tyto 听译

[English](README.md) | **中文**

开会用的 macOS 悬浮窗：把会议里的话实时转成文字、原文和译文对照显示，点一下就能针对某几句话生成回复；截一下 Teams、Slack、邮件的屏幕，就能拿到写好的回复，⌘V 直接发。**共享屏幕时对方看不见它。**

Tyto 是仓鸮属的拉丁名——仓鸮在黑暗里只靠听声音就能定位。

## 能做什么

- **共享屏幕时看不见**：悬浮窗和设置窗口都不会出现在 Zoom、Teams、Google Meet、飞书的屏幕共享里（[验证方法和结果](docs/share-check.md)）。
- **两路声音分开听**：远端是会议软件里对方的声音（录系统声音），本地是麦克风收到的声音（你和会议室里的人）。用云端识别时还能分出说话人 1、2、3，点名字就能改成「我」「Alice」。
- **原文 / 译文对照**：选好主语言，别的语言的句子下面会多一行小一号、颜色淡一些的译文，一键开关。数字、日期、金额、人名和你设的关键词会自动高亮，问句打上「提问」标记。
- **点一下就回复**：点一句、多选几句，或者「回复最近的话」。回复会结合这场会议的背景和你选的技能，分三段：对方的意思、可以直接说出口的回复、中文对照。
- **回复面板**：生成的回复都留在悬浮窗旁边的一列里（⌃⌥B 开关），最新的在上面，可以删，跟着会话保存。会议里的回复下面会接上「你实际说的」：对方那句之后、对方再说别的之前，本地叫「我」的人说的话，并标上「基本照着说 / 改了说法 / 没回」；字幕里这几句旁边有个小图标，点了跳到对应的回复。导出的会议记录里也有这份对比。
- **提词器**：会前准备的材料放在一个单独的透明窗口里（⌃⌥N），可以拖到任何地方，比如摄像头正下方。支持 Markdown、HTML、纯文本，文件改了马上刷新。顶上一条始终显示现在在哪一节，点开是目录；⌃⌥↑ / ⌃⌥↓ 跳上一节、下一节。开着「跟读」时，你照着稿子说，它就滚到你说到的那一段并高亮。对方问到稿子里某一节的内容时，底下会提示，⌃⌥J 跳过去。比对在本机做，也会用译文比，所以说英文也能对上中文稿。
- **截屏回复**：⌃⌥S 截下最前面的 App（比如 Teams 的聊天），读懂谁在说什么、要你做什么，给出三个能直接粘贴的回复，第一个自动放进剪贴板。
- **模型随便换**：服务商只配一次，回复、看图、翻译、语音识别各选各的模型。支持 Anthropic、OpenAI、OpenRouter、Gemini、DeepSeek、通义千问、硅基流动、Groq、Soniox、Deepgram、本机 Ollama / LM Studio，以及任何 OpenAI 兼容的接口。
- **外观**：macOS 26 的玻璃材质，三套配色；底色可以从完全透明调到很深，字号可调。

## 安装

要求 **macOS 26** 或更新，Apple 芯片。

1. 到 [Releases](../../releases) 下载最新的 `Tyto-x.y.z.dmg`，打开。
2. 把 `Tyto` 拖到旁边的「应用程序」上，再从「应用程序」里打开。

应用已经过 Apple 公证，可以直接打开。从别的地方打开时，Tyto 会问要不要把自己移到「应用程序」。

- **自动更新**：每天查一次 GitHub 上有没有新版，有就在后台下载好，下次退出 Tyto 时装上，开会时不打扰。「设置 → 通用」里可以关掉或马上检查；Tyto 菜单里也有「检查更新…」。每个更新包都要先用 Tyto 的签名密钥验过才会装。
- **常驻**：程序坞和菜单栏（耳朵图标）里都有 Tyto。关掉或最小化设置窗口，Tyto 还在后台运行，悬浮窗和快捷键照常可用；要退出用 ⌘Q。「设置 → 通用」里可以开机自动打开，也可以不在程序坞显示、只留菜单栏图标。

## 第一次使用

第一次打开会弹出「会话与设置」。界面语言跟随系统（中文或英文），随时可以在菜单栏图标 →「语言 · Language」或「外观」页里切换。

1. **模型与服务**：添加一个服务商并填上 key（比如 OpenRouter，一个 key 就能用 Claude、GPT、Gemini），然后在「各个用途 → 回复」里选模型。只想先试试字幕和翻译，可以跳过这一步——本机识别和本机翻译都不要 key。
2. **翻译**：选好主语言；用 Apple 本机翻译的话，点「下载」把语言包装上（没装时悬浮窗会提示，点「去下载」直接跳过去）。
3. 按 **⌃⌥L** 开始听。第一次会请求两项系统权限：**系统录音**（听会议软件里的声音）和 **麦克风**（听会议室里的声音）。
4. 要用截屏回复，再在「系统设置 → 隐私与安全性 → 录屏与系统录音」里打开 Tyto，然后重开一次 Tyto。

「权限与关于」页能看到每项权限的状态，点一下直接跳到对应的系统设置。

## 日常用法

- **开会前**：在「会话」里写几句背景（会议目的、参会的人、你的角色、要用到的术语）和关键词，勾上要用的技能。生成回复时都会带上。
- **开会时**：⌃⌥L 开始听。悬浮窗里实时出现字幕；点一句选中，再点「回复」或按 ⌃⌥R。
- **回别人消息时**：在 Teams / Slack / 邮件里按 ⌃⌥S，几秒后回复就在剪贴板里了，⌘V 发出去。想换个说法，在回复卡片底下写一句"想怎么回"（比如"婉拒""用中文"），点「重新生成」。
- **调外观**：悬浮窗顶部的调色盘图标里改主题、字色、底色浓度和字号。字色默认「自动」：悬浮窗后面是白底文档、网页时换黑字配浅色玻璃，是会议视频这类暗画面时用白字；也可以固定白字或黑字。字幕有「头像」「细线」两种样式（设置 → 外观）；拖边缘改大小，菜单里「恢复默认大小和位置」随时复原。默认高度约为屏幕的 38%，宽约 26%，靠右放，不挡会议画面。

## 快捷键

会议软件在前台时也能用。

| 快捷键 | 作用 |
|---|---|
| ⌃⌥L | 开始 / 停止听 |
| ⌃⌥R | 回复（选中的句子，或最近的话） |
| ⌃⌥S | 截屏回复（最前面的 App，或在设置里改成整个屏幕） |
| ⌃⌥A | 截屏回复：框选一块 |
| ⌃⌥T | 显示 / 隐藏悬浮窗 |
| ⌃⌥B | 打开 / 收起回复面板 |
| ⌃⌥N | 打开 / 收起提词器 |
| ⌃⌥↑ / ⌃⌥↓ | 提词器：上一节 / 下一节（提词器开着时） |
| ⌃⌥J | 提词器：跳到对方刚提到的那一节 |
| ⌃⌥P | 点击穿透开 / 关（鼠标点到悬浮窗下面的窗口；穿透时按住 ⌥ 把鼠标移到悬浮窗上可以临时操作） |
| ⌃⌥Q | 退出 |

## 模型与服务

「会话与设置 → 模型与服务」分两部分：

- **服务商**：点「添加」从模板里选一个，填上 key。key 存在钥匙串里。
- **各个用途**：回复、看图、翻译、语音识别，每个都选"服务商 + 模型"。点模型旁边的 ⌄ 可以从服务商读模型列表，也可以直接输入。

| 模板 | 能做什么 |
|---|---|
| Anthropic | 回复、看图（Claude） |
| OpenAI | 回复、看图、语音转写、听写 |
| OpenRouter | 回复、看图、听写；一个 key 用几百个模型 |
| Google Gemini | 回复、看图、听写 |
| DeepSeek | 回复 |
| 通义千问 | 回复、看图 |
| 硅基流动 | 回复、看图、语音转写 |
| Groq | 回复、语音转写（Whisper，很快） |
| Ollama / LM Studio 本机 | 回复、看图；数据不出这台 Mac |
| Soniox / Deepgram | 实时语音识别 |
| 自定义 | 任何 OpenAI 兼容的接口（公司网关、自建 Whisper 服务……） |

## 语音识别的四种方式

在「听写」页选：

| 方式 | 服务商 | 特点 |
|---|---|---|
| Apple 本机 | — | 免费、不联网。一路只认一种语言，不区分说话人 |
| 实时识别服务 | Soniox、Deepgram | 边说边出字，分得出说话人，最适合开会 |
| 语音转写接口 | OpenAI、Groq、硅基流动、自建 Whisper | 停顿 0.7 秒算一句，一句一句上传，比实时慢一两秒 |
| 让模型听写 | OpenRouter、Gemini 等能听音频的模型 | 同上；多种语言混着说也行 |

外放开会时，麦克风会收到对方的声音。打开「去掉回声」后，本地出现的、和远端同时说出且大部分词相同的那句会被去掉；你复述对方的话来回答不受影响。

## 截屏回复

**截哪里**：最前面的 App（默认，会认出是哪个 App）、整个屏幕，或框选（⌃⌥A）。也可以用剪贴板里已有的图片。

**怎么读懂截图**：

| 方式 | 截图去哪 | 适合 |
|---|---|---|
| 图片直接给回复模型（默认） | 回复模型的服务商 | 最准 |
| 先用看图模型读图 | 看图模型选本机的，就不出这台 Mac | 在意隐私，又要看懂版面 |
| 只用本机 OCR | 不出这台 Mac | 只认字，免下载，0.3 秒 |

**本机看图模型**（通过 [Ollama](https://ollama.com)，在「截屏回复」页一键下载），16 GB 内存的笔记本也跑得动：

| 模型 | 大小 | 说明 |
|---|---|---|
| Qwen3-VL 2B（推荐） | 1.9 GB | 认字，也看得懂聊天和邮件 |
| GLM-OCR 0.9B | 1.8 GB | 专门把字转出来，不理解内容 |
| Qwen3-VL 4B | 3.3 GB | 更准 |

系统自带的文字识别（Apple Vision）不用下载，一直可用。

**进阶：百度 Unlimited-OCR-2（MLX 版，可选）**。2026-10-26 开源，MIT 许可证，约 33 亿参数的混合专家模型（每次只用约 5 亿），专门做文档解析，识字比系统自带的准（实测把系统 OCR 认错的"I need"、问号、破折号都认对了），还给出每段文字的位置。它不走 Ollama，要单独跑一个本机服务：

```bash
uv venv --python 3.12 ~/.tyto-ocr
uv pip install --python ~/.tyto-ocr/bin/python "git+https://github.com/shuuul/mlx-vlm.git@223c2980fe4b48bd73faeb9e5bb1f1eacafffb49"
~/.tyto-ocr/bin/python scripts/unlimited-ocr-server.py      # 第一次下载 4 位版约 2.5 GB，端口 18780
```

然后在「模型与服务」添加「自定义接口」，地址 `http://127.0.0.1:18780/v1`；「看图」选它，模型填 `mlx-community/Unlimited-OCR-2-4bit`；截屏回复选「先用看图模型读图」。

实测（M4 Pro）：聊天截图读一次 1.4 秒，一整页密排的中英文约 5 秒，内存约 2.8 GB；整个截屏回复（读图 + 云端写回复）约 5 秒。M1 Pro 16 GB 能跑，估计慢一倍左右。Linux 只有 CPU 时官方代码也能跑（Triton 加速只在 NVIDIA 显卡上用），但要 bf16 约 7 GB 内存，速度估计一张几十秒，不适合边开会边用；有 NVIDIA 显卡的 Linux 用官方的 SGLang 最快。

## 隐私：哪些数据会离开这台 Mac

| 数据 | 去哪 |
|---|---|
| 会议声音 | 用 Apple 本机识别时不出本机；用云端识别时发给你选的识别服务 |
| 字幕文字 | 用 Apple 本机翻译时不出本机；生成回复、大模型翻译时发给你选的模型服务 |
| 提词器的材料 | 只在本机读；跟读和提示都在本机比对 |
| 检查更新 | 每天从 GitHub Releases 下载一次 `appcast.xml`，不发送任何关于你或这台 Mac 的信息 |
| 悬浮窗、提词器后面的画面 | 字色「自动」时每 2.5 秒取一次那块区域，缩到 16×16 算平均亮度，只在本机算，不存图；字色固定时不取 |
| 截图 | 按你选的读图方式（见上表）；选本机模型或只用 OCR 时不出本机 |
| key | 只存在这台 Mac 的钥匙串里 |
| 会议记录 | 只存在 `~/Library/Application Support/Tyto/sessions/` |

## 从源码编译

需要 Xcode 26（Swift 6.2）。

```bash
scripts/build-app.sh               # 开发版：build/Tyto.app（用 Apple Development 证书签名）
open build/Tyto.app
scripts/build-app.sh ShareCheck    # 共享屏幕验证程序：build/TytoShareCheck.app
scripts/release.sh notes.md        # 发布版：Developer ID 签名 + 公证 → dist/Tyto-<版本>.dmg、.zip、appcast.xml
scripts/test-update.sh             # 真的走一遍自动更新：旧版找到、验签、装上新版；篡改过的包拒绝
swift scripts/make-icon.swift owl icon.png && scripts/build-icon.sh icon.png   # 重画程序图标
```

更新包用 EdDSA 密钥签名，私钥不在仓库里（默认 `~/.config/tyto-release/sparkle-ed25519-private.key`，公钥是 `Resources/Tyto-Info.plist` 里的 `SUPublicEDKey`）。`build/` 里的开发版不会自动更新。

系统权限是按签名记的，用固定证书签名，重新编译后权限不会丢。

## 自测命令

不开会也能检查各个环节（都在 `build/Tyto.app/Contents/MacOS/Tyto` 后面加参数）：

| 参数 | 检查什么 |
|---|---|
| `--selftest-speech <音频> [--locale en-US]` | 按设置的识别方式识别一个音频文件，再翻译 |
| `--selftest-reply` | 用回复模型对一段示例对话生成回复 |
| `--selftest-screenshot <图片> [--app 名字]` | 截屏回复的完整流程 |
| `--selftest-capture frontWindow` | 截最前面的 App 并认出名字 |
| `--selftest-models <服务商 id>` | 读服务商的模型列表 |
| `--selftest-settings` | 读出现在的设置（只看不写） |
| `--selftest-echo` / `--selftest-deepgram` | 去回声规则、Deepgram 消息解析 |
| `--render-preview <文件夹>` / `--render-settings <文件夹>` | 把悬浮窗、设置窗口画成图片（不截屏） |
| `--selftest-glass <文件夹> [--light] [--auto]` | 真实玻璃效果（只截 Tyto 自己的窗口）；`--light` 盖在白底页面上，`--auto` 按自动字色画 |
| `--selftest-backdrop` | 字色自动：量白底页面和会议画面的亮度，看选白字还是黑字 |
| `--selftest-followup` | 回复建议之后「你实际说的」：找哪几句、判照着说 / 改了说法 / 没回；回复面板贴哪一边 |
| `--selftest-prompter [文件夹]` | 在真窗口里测提词器：目录、跟读、对方提到时的提示（英文稿和中文稿）、别人写的 HTML 的字色、改了文件自动刷新；给了文件夹就再截图 |

以上都可以加 `--settings-json '{...}'` 临时改设置，不会写回。运行日志在 `~/Library/Logs/Tyto.log`。

## 代码结构

```
Sources/Tyto/
  App/        启动、菜单、程序坞、全局快捷键、自动更新（Sparkle）、移到「应用程序」、开机自动打开
  Audio/      系统声音（Core Audio 进程音频捕获）、麦克风、重采样
  Speech/     识别：Apple SpeechAnalyzer、Soniox、Deepgram、按停顿切句上传
  Translate/  Apple 本机翻译、大模型翻译
  Screenshot/ 截前台 App / 整屏 / 框选、本机 OCR
  LLM/        Claude / OpenAI 兼容 / Ollama 客户端、模型列表、提示词
  Model/      会话、设置（服务商 + 用途）、技能
  Prompter/   提词器：Markdown 转 HTML、网页视图、跟读和提示的比对
  UI/         悬浮窗、主题、高亮、设置窗口
  Dev/        自测、运行日志
Sources/ShareCheck/   共享屏幕验证程序
```

## 已知限制

- 远端录的是除 Tyto 以外所有 App 的声音，开会时别放音乐和视频。
- 悬浮窗里的下拉菜单是系统画的，共享屏幕时弹出的那一下可能被看到。
- Soniox、Deepgram 按官方协议实现，还没在真实会议里长时间跑过。
- Google Meet 在 Chrome 里共享时的隐藏效果还没实测（Chrome 走的也是 ScreenCaptureKit，同一条路径已经测过）。
